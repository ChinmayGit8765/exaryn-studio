# Ollama

Local model serving. It is what makes "no cloud" a real claim rather than a preference in two projects.

[[ALFRED]] runs entirely on it — that is the point of the project. [[smartc]] uses it for opt-in contract patching, so source code that is often the most sensitive thing in a repo never leaves the machine.
