# TypeScript

The default for anything with a UI or a package to publish. [[Prompterjack]] is TypeScript end to end across a Turborepo monorepo; [[Worktree Optimiser]] and [[smartc]] are Node CLIs; [[Contact Flow]] runs NestJS on the API side and Next.js on the front.

The pattern across all of them: types at the boundary. Every one of these projects validates at the edge and trusts nothing that crossed a wire.
