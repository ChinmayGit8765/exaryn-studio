# Claude

The model the studio actually builds with. Over a billion tokens this year, tracked on the site's token meter.

Two projects exist specifically to make working with it better: [[Claude Work Manager]] runs a fleet of Claude Code sessions across worktrees, and [[Worktree Optimiser]] gives those sessions running environments through [[MCP]].

The working style it encourages is in [[Context Engineering]]; the supervision model is in [[Agent Structure]].
