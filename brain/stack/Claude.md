# Claude

The model family the studio actually builds with. Two projects exist
specifically to make working with it better: [[Claude Work Manager]] runs a
fleet of Claude Code sessions across worktrees, and [[Worktree Optimiser]]
gives those sessions running environments through [[MCP]].

Token-use figures on the site's front page are a hand-updated studio estimate,
not a measured metric.

The working style it encourages is in [[Context Engineering]]; the supervision
model is in [[Agent Structure]].
