## The shape of it

Seventeen projects across five categories, ten autonomous agents, five
scheduled systems, thirty-five repositories. One person. The pattern that
repeats everywhere:

> **Cron job → Python script → committed JSON → static site.**

No servers to keep alive, no databases to back up, no bill when nobody visits.
[[Daily Signal Pipeline]] and [[Pirate Picker]] and [[Fan Suite Bot]] are all
the same idea wearing different hats — see [[Agent Patterns]].
