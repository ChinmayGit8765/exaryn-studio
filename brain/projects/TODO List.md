# TODO List

*A deliberately simple todo app built like a real codebase — .NET + Angular.*

A todo app that is deliberately boring on the surface and deliberately rigorous underneath: .NET Web API with proper layering, Angular frontend with presentational components, tests on both sides. Subtasks, inline edit, active/completed tabs. Built as a reference implementation for how a small app should actually be structured.

## How it is put together

.NET Web API split into real layers — controllers, services, data — rather than one fat controller. Angular front end keeps components presentational and pushes state up. Both halves have tests.

## What is actually in it

- Subtasks, inline edit, and active/completed tabs
- Proper layering in the API instead of logic in controllers
- Presentational Angular components with state kept above them
- Tests on both the .NET and the Angular side

## What it taught

> The point was never the todo app. It was having one small codebase where the structure is right, to compare bigger ones against.
