# Prompterjack Crew Designer

The public Agent Architect surface on PrompterJack: design agent roles,
routing and handoffs, then export an implementation scaffold. It is one of
several connected tools on [prompterjack.com](https://prompterjack.com/products).
The live landing page leads with repository context — scanning a public GitHub
repo and preparing `CLAUDE.md` / `AGENTS.md` — not with this canvas.

This note describes the agent-design product as listed publicly. It does not
claim a fixed list of export frameworks, real-time co-editing, or any surface
that is not on the public products page.
